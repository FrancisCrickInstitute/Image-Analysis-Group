# Accessing Imaris Floating Licenses
Imaris is a commercial software package for visualisation, segmentation, and quantitation of 3D and 4D imaging data. CALM provides a limited number of floating licenses for Imaris.

## CALM workstations and Virtual Machines
We also provide access to **Imaris** on the following systems:
- **3 physical workstations**, located in SW311. Can also be accessed remotely.
- **2 virtual machines** (*VM_IM*).

Imaris is **pre-installed** in all of these systems, and ready to use.
You can book time through these machines through [PPMS](https://ppms.eu/crick/?LM), as you would with other imaging equipment. 

---

> ⚠️ **Important**: You must be connected to the Crick network to access the license server.
> If you're working remotely, ensure you are connected to the **Crick VPN** before proceeding.

## How to Set Up and Access a Floating License

1. **Start Imaris**.
2. Go to **File → Preferences**, then click on **Imaris Configurator** at the bottom of the Preferences dialog.
3. In the new window, select **License – Install / Upgrade License**.
4. Choose **Define Floating License Server**.
5. Enter the floating client license **Order  ID**:
   `xffn-js3t-tya2-zdrh`
   and click **Download Client License**.
6. When prompted for the **Floating License Server Name**, enter:  
   `imaris.thecrick.org`
7. Click **Install Licenses**.  
   *(You may need to enlarge the window to see this button.)*
8. Click **Finish** and **restart Imaris** for the changes to take effect.

## Important notes
- 🔒 **Licenses are limited**, so please:
  - Only use Imaris when needed.
  - **Log out and close Imaris** when you're done to free up the license for your fellow researchers!
