## Our Projects

### Spatial & Multiplex Imaging
* [CellSurvey](https://github.com/FrancisCrickInstitute/CellSurvey) – GPU-accelerated pipeline for spatial omics (Sopa/SpatialData)

### Quality Control
* [CrosstalkPy](https://github.com/FrancisCrickInstitute/CrosstalkPy) – Detect channel bleed-through in microscopy
* [flag-qc](https://github.com/FrancisCrickInstitute/flag-qc) – Bioimage quality control tools

### Image Analysis
* [3D Nuclear Intensity Quantification](https://github.com/FrancisCrickInstitute/Simple-3D-Nuclear-Intensity-Quantification) – 3D nuclear intensity tools
* [Object Midline Detection](https://github.com/FrancisCrickInstitute/Object-Midline-Detection) – Bioimage midline detection
* [Cell Classifier](https://github.com/FrancisCrickInstitute/cell-classifier) – Machine learning for cell classification
* [BRAINSAW Data Processing](https://github.com/FrancisCrickInstitute/brainsaw-data-processing) – BRAINSAW pipeline
* [Pancreatic Tissue Integrity (QuPath)](https://github.com/FrancisCrickInstitute/pancreatic-tissue-integrity-qupath) – QuPath tools for tissue assessment

### Tools & Utilities
* [Image Analysis Template](https://github.com/FrancisCrickInstitute/Image_Analysis_Template) – Project template
* [Data Prospector](https://github.com/FrancisCrickInstitute/Data-Prospector) – AI-driven dataset exploration
* [BioImage Analysis Bot (biabot)](https://github.com/FrancisCrickInstitute/biabot) – AI triage for bioimage projects

### Training & Education
* [Napari Tutorial](https://github.com/FrancisCrickInstitute/napari-tutorial) – Modular napari course
* [Intro to Image Analysis](https://github.com/FrancisCrickInstitute/introduction-to-image-analysis) – Training workshop
* [Reproducible Statistics](https://github.com/FrancisCrickInstitute/Enhancing-Reproducibility) – Notebooks on reproducibility

> Explore the [full list of our repositories](https://github.com/orgs/FrancisCrickInstitute/teams/crick-image-analysis-group/repositories) on GitHub.
